The narration is the receipt
There is no tool-call panel to keep in sync with the transcript. The agent's prose runs full width with no avatar and no bubble — it is the page's own voice, and only the operator's turns are boxed. A tool call collapses to one muted line naming how many commands ran and which tool ran them; the parameters and the output are one click away, not in your face. Reasoning collapses the same way, to a single truncated line. Progress is read off the stream itself — each write lands as a line as it happens — so there is no counter strip to keep honest, and nothing that can disagree with the Assets page. The one number in the chrome is the context meter in the crumb bar: a ring and a token count, there because a long import is the thing most likely to run the window out, and clickable to see what is holding the window.

Rich content, same ink
Everything the agent can emit renders in the thread's own vocabulary: inline bold, italic, strikethrough, links and code; headings, nested and task lists; blockquotes with the line they came from; tables that fill the thread width rather than scrolling; code blocks framed with a filename and a copy affordance; and small flow figures for relationships. Syntax highlighting is carried by weight and tone, not colour — the palette stays monochrome. Anything that cannot wrap — a long URL, a token, a header dump — scrolls inside its own block so the 800px measure never breaks.
